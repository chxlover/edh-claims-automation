## v6.1 Design (TAB-walk)

### Loop per row (hanggang mapagod ang folder files — ang huli ay ESA)

1. `_focused_row_y()` — hanapin ang focused row via BLUE HIGHLIGHT BAND
   (`find_highlight_band` mula sa doc_type module — pixel scan, walang OCR):
   screenshot → popup crop → largest blue run na may top >= 50px mula sa
   popup top (para i-exclude ang title bar / header) at height >= 8px →
   return screen center Y. Retry hanggang 2.0s (render delay pagkatapos ng TAB).
2. `_copy_row_path(row_y)` — right-click (ROW_COPY_X=700) → context menu
   "copy" (MN_GETHMENU/GetMenuItemRect; keyboard down+enter fallback na
   menu-confirmed lang) → clipboard = FULL ABSOLUTE PATH. (Existing v6
   method, hindi babaguhin — proven sa live run.)
3. `match_copied_path_to_file(path, folder_files, expected_parent)` —
   exact basename + patient-folder parent. (Existing, proven.)
4. `_type_row_doc(doc, row_y, ...)` — click doc field (497) → type doc →
   click arrow (519) → TAB. (Existing, proven.) Ang TAB ay gumagalaw ng
   grid focus sa SUSUNOD na row — si HBSys ang mag-a-auto-scroll kapag
   kailangan. Tapos: balik sa step 1.

Exit: lahat ng folder files ay naproseso (row identity = clipboard path,
hindi position) → Upload (598,730) → Enter (OK) → Close (1408,734)
(v5.2 flow, hindi babaguhin).

### Guardrails (pinapanatili — walang bawas)

- Never-guess: copy failure, foreign path (VILLARUEL-type row), o
  duplicate focus (focus na bumalik sa nagawang row) → ABORT bago ang
  Upload, na may buong path sa log.
- MAX_DOC_ROWS=40 file cap.
- Isang debug crop lang simula (diagnosis); walang per-view OCR, walang
  fingerprint, walang scroll detection — tatanggalin ang buong
  no-progress machinery dahil walang scroll.

b. **Idagdag ang `_focused_row_y()`** (bagong method, pagkatapos ng
   `assign_doc_types_and_upload`):

```python
def _focused_row_y(self) -> Optional[int]:
    """Screen Y of the focused (blue-highlighted) grid row, or None.

    Screenshots the popup crop and locates the blue selection band via
    `find_highlight_band` (pixel scan, no OCR). Bands whose top is within
    50px of the popup top are ignored (title bar / grid header); the
    band center is returned in screen coordinates. Retries up to 2s —
    the band may take a moment to render after a TAB.
    """
    deadline = time.time() + 2.0
    while time.time() < deadline:
        screenshot = pyautogui.screenshot()
        crop_box = self._popup_crop_box(screenshot)
        self._last_crop_box = crop_box
        crop = screenshot.crop(crop_box)
        band = find_highlight_band(crop)
        if band is not None:
            top, bottom = band
            if top >= 50 and bottom - top >= 8:
                return crop_box[1] + (top + bottom) // 2
        sleep_short(0.15)
    return None
```
